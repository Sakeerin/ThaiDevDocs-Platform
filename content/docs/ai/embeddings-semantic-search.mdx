## Semantic Search vs Keyword Search

**Keyword search** หา exact match — "eager loading" ไม่เจอ "N+1 problem"

**Semantic search** หาความหมายใกล้เคียง — "N+1 problem" จะ match กับ "eager loading" ได้

```text
Text → Embedding Model → Vector (1536 dimensions)
Query → Embedding → Compare with stored vectors → Rank by similarity
```

## Embedding Models

| Model | Dimensions | ใช้เมื่อ |
|---|---|---|
| `text-embedding-3-small` | 1536 | General purpose, ถูก |
| `text-embedding-3-large` | 3072 | ต้องการ accuracy สูง |
| `multilingual-e5-large` | 1024 | ภาษาไทย + อังกฤษ mixed |

<Callout type="info">
`text-embedding-3-small` รองรับภาษาไทยได้ดีและราคาถูก — เหมาะสำหรับ docs platform
</Callout>

## EmbeddingService

```php
// app/Services/EmbeddingService.php
class EmbeddingService
{
    public function embed(string $text): array
    {
        $text = $this->preprocess($text);

        $response = Http::withHeaders([
            'Authorization' => 'Bearer ' . config('services.openai.api_key'),
        ])->post('https://api.openai.com/v1/embeddings', [
            'model' => 'text-embedding-3-small',
            'input' => $text,
        ])->throw();

        return $response->json('data.0.embedding');
    }

    public function embedBatch(array $texts): array
    {
        $response = Http::withHeaders([
            'Authorization' => 'Bearer ' . config('services.openai.api_key'),
        ])->post('https://api.openai.com/v1/embeddings', [
            'model' => 'text-embedding-3-small',
            'input' => $texts,
        ])->throw();

        return collect($response->json('data'))
            ->sortBy('index')
            ->pluck('embedding')
            ->all();
    }

    private function preprocess(string $text): string
    {
        $text = strip_tags($text);
        $text = preg_replace('/\s+/', ' ', $text);
        return mb_substr(trim($text), 0, 8000);
    }
}
```

## Cosine Similarity (PHP)

```php
// app/Support/VectorMath.php
class VectorMath
{
    public static function cosineSimilarity(array $a, array $b): float
    {
        $dotProduct = 0;
        $normA = 0;
        $normB = 0;

        for ($i = 0; $i < count($a); $i++) {
            $dotProduct += $a[$i] * $b[$i];
            $normA += $a[$i] ** 2;
            $normB += $b[$i] ** 2;
        }

        if ($normA == 0 || $normB == 0) return 0;

        return $dotProduct / (sqrt($normA) * sqrt($normB));
    }
}
```

## ContentSearchService

```php
// app/Services/ContentSearchService.php
class ContentSearchService
{
    public function __construct(private EmbeddingService $embedder) {}

    public function semanticSearch(string $query, int $limit = 10): Collection
    {
        $queryVector = $this->embedder->embed($query);

        // pgvector path
        if (config('database.default') === 'pgsql') {
            return $this->pgvectorSearch($queryVector, $limit);
        }

        // Fallback: in-memory cosine similarity
        return ContentSection::whereNotNull('embedding')
            ->get()
            ->map(function ($section) use ($queryVector) {
                $section->similarity = VectorMath::cosineSimilarity(
                    $queryVector,
                    $section->embedding
                );
                return $section;
            })
            ->sortByDesc('similarity')
            ->take($limit)
            ->values();
    }

    private function pgvectorSearch(array $vector, int $limit): Collection
    {
        $vectorStr = '[' . implode(',', $vector) . ']';

        return collect(DB::select("
            SELECT *, 1 - (embedding <=> ?::vector) AS similarity
            FROM content_sections
            WHERE embedding IS NOT NULL
            ORDER BY embedding <=> ?::vector
            LIMIT ?
        ", [$vectorStr, $vectorStr, $limit]));
    }
}
```

## Hybrid Search (Semantic + Keyword)

```php
public function hybridSearch(string $query, int $limit = 10): Collection
{
    $semantic = $this->semanticSearch($query, $limit * 2);
    $keyword = ContentSection::whereFullText(['title', 'content'], $query)
        ->limit($limit * 2)
        ->get();

    // Reciprocal Rank Fusion
    $scores = [];

    foreach ($semantic as $rank => $item) {
        $scores[$item->id] = ($scores[$item->id] ?? 0) + 1 / ($rank + 60);
    }

    foreach ($keyword as $rank => $item) {
        $scores[$item->id] = ($scores[$item->id] ?? 0) + 1 / ($rank + 60);
    }

    arsort($scores);
    $topIds = array_slice(array_keys($scores), 0, $limit);

    return ContentSection::whereIn('id', $topIds)
        ->get()
        ->sortBy(fn ($item) => array_search($item->id, $topIds));
}
```

<Callout type="tip">
Hybrid search ดีกว่า semantic อย่างเดียวสำหรับ technical docs — keyword จับ exact terms (เช่น `withCount`) semantic จับ conceptual queries
</Callout>

## Search API

```php
// routes/api.php
Route::get('/search', function (Request $request, ContentSearchService $search) {
    $request->validate(['q' => 'required|string|min:2|max:200']);

    $results = $search->hybridSearch($request->q);

    return response()->json([
        'query'   => $request->q,
        'results' => $results->map(fn ($r) => [
            'title'      => $r->title,
            'snippet'    => Str::limit($r->content, 200),
            'path'       => $r->source_path,
            'similarity' => $r->similarity ?? null,
        ]),
    ]);
});
```

## Cache Embeddings

```php
public function embed(string $text): array
{
    $hash = hash('sha256', $text);

    return Cache::remember("embedding:{$hash}", 86400 * 7, function () use ($text) {
        return $this->callEmbeddingApi($text);
    });
}
```
