## LINE Bot + AI Architecture

```text
User ส่งข้อความใน LINE
    ↓
LINE Platform → Webhook POST ไป Laravel
    ↓
Verify signature → Parse event
    ↓
RAG/Claude สร้างคำตอบ
    ↓
Reply message กลับ LINE
```

<Callout type="info">
LINE เป็น messaging platform ที่ใช้กันมากที่สุดในไทย — เหมาะสำหรับ customer support bot และ FAQ automation
</Callout>

## Webhook Controller

```php
// app/Http/Controllers/LineWebhookController.php
use LINE\Clients\MessagingApi\Api\MessagingApiApi;
use LINE\Clients\MessagingApi\Model\ReplyMessageRequest;
use LINE\Clients\MessagingApi\Model\TextMessage;
use LINE\Parser\EventRequestParser;
use LINE\Parser\Exception\InvalidEventRequestException;
use LINE\Parser\Exception\InvalidSignatureException;

class LineWebhookController extends Controller
{
    public function __construct(
        private AiQaService $qa,
        private LineConversationService $conversation,
    ) {}

    public function __invoke(Request $request)
    {
        $signature = $request->header('X-Line-Signature');
        $body = $request->getContent();

        try {
            $events = EventRequestParser::parseEventRequest(
                $body,
                config('services.line.channel_secret'),
                $signature
            );
        } catch (InvalidSignatureException $e) {
            return response('Invalid signature', 400);
        }

        foreach ($events as $event) {
            if ($event instanceof MessageEvent && $event->getMessage() instanceof TextMessageContent) {
                $this->handleTextMessage($event);
            }
        }

        return response('OK', 200);
    }

    private function handleTextMessage(MessageEvent $event): void
    {
        $userId = $event->getSource()->getUserId();
        $text = $event->getMessage()->getText();
        $replyToken = $event->getReplyToken();

        // เก็บ conversation history
        $this->conversation->addMessage($userId, 'user', $text);

        // ตอบด้วย RAG
        $result = $this->qa->ask($text);
        $this->conversation->addMessage($userId, 'assistant', $result['answer']);

        $this->reply($replyToken, $result['answer'], $result['sources']);
    }

    private function reply(string $replyToken, string $text, array $sources): void
    {
        $client = new MessagingApiApi(
            client: new Client(),
            config: new Configuration([
                'accessToken' => config('services.line.channel_access_token'),
            ])
        );

        $messages = [new TextMessage(['type' => 'text', 'text' => $text])];

        // เพิ่ม sources ถ้ามี
        if (!empty($sources)) {
            $sourceText = "📚 อ้างอิง:\n" . collect($sources)
                ->map(fn ($s) => "• {$s['title']}")
                ->join("\n");
            $messages[] = new TextMessage(['type' => 'text', 'text' => $sourceText]);
        }

        $client->replyMessage(new ReplyMessageRequest([
            'replyToken' => $replyToken,
            'messages'   => $messages,
        ]));
    }
}
```

## Conversation Context

```php
// app/Services/LineConversationService.php
class LineConversationService
{
    private const MAX_HISTORY = 10;
    private const TTL = 3600;

    public function addMessage(string $userId, string $role, string $content): void
    {
        $key = "line:conversation:{$userId}";
        $history = Cache::get($key, []);
        $history[] = ['role' => $role, 'content' => $content];

        if (count($history) > self::MAX_HISTORY * 2) {
            $history = array_slice($history, -self::MAX_HISTORY * 2);
        }

        Cache::put($key, $history, self::TTL);
    }

    public function getHistory(string $userId): array
    {
        return Cache::get("line:conversation:{$userId}", []);
    }
}
```

## Rate Limiting & Quota

```php
// จำกัด AI queries ต่อ user ต่อวัน
$key = "line:ai-quota:{$userId}";
$count = Cache::get($key, 0);

if ($count >= 20) {
    $this->reply($replyToken, 'คุณใช้ quota ครบแล้ววันนี้ กรุณาลองใหม่พรุ่งนี้', []);
    return;
}

Cache::put($key, $count + 1, now()->endOfDay());
```

<Callout type="warning">
LINE reply token ใช้ได้ครั้งเดียวและหมดอายุใน 30 วินาที — process AI เร็วหรือใช้ push message สำหรับ response ช้า
</Callout>
