## Claude API คืออะไร?

**Claude** จาก Anthropic เป็น LLM ที่เหมาะกับ coding, analysis และ long-context tasks — เรียกผ่าน REST API จาก Laravel ได้

## ติดตั้ง SDK

```bash
composer require anthropic-ai/sdk
```

```bash

ANTHROPIC_API_KEY=sk-ant-api03-xxxxx
```

## ClaudeService

```php
// app/Services/ClaudeService.php
namespace App\Services;

use Anthropic\Client;
use Anthropic\Messages\MessageParam;

class ClaudeService
{
    private Client $client;

    public function __construct()
    {
        $this->client = new Client(
            apiKey: config('services.anthropic.api_key')
        );
    }

    public function chat(string $userMessage, ?string $systemPrompt = null): string
    {
        $messages = [
            MessageParam::with(role: 'user', content: $userMessage),
        ];

        $params = [
            'model'      => config('services.anthropic.model'),
            'max_tokens' => config('services.anthropic.max_tokens'),
            'messages'   => $messages,
        ];

        if ($systemPrompt) {
            $params['system'] = $systemPrompt;
        }

        $response = $this->client->messages->create($params);

        return $response->content[0]->text;
    }

    public function chatWithHistory(array $messages, ?string $systemPrompt = null): string
    {
        $params = [
            'model'      => config('services.anthropic.model'),
            'max_tokens' => config('services.anthropic.max_tokens'),
            'messages'   => $messages,
        ];

        if ($systemPrompt) {
            $params['system'] = $systemPrompt;
        }

        $response = $this->client->messages->create($params);
        return $response->content[0]->text;
    }
}
```

## Controller + Route

```php
// app/Http/Controllers/AiChatController.php
class AiChatController extends Controller
{
    public function __construct(private ClaudeService $claude) {}

    public function ask(Request $request)
    {
        $request->validate(['message' => 'required|string|max:2000']);

        $answer = $this->claude->chat(
            userMessage: $request->message,
            systemPrompt: 'คุณเป็นผู้ช่วยด้าน Laravel ตอบเป็นภาษาไทย กระชับและมี code example'
        );

        return response()->json(['answer' => $answer]);
    }
}
```

## Streaming Response

```php
public function stream(Request $request)
{
    return response()->stream(function () use ($request) {
        $stream = $this->claude->client->messages->createStreamed([
            'model'      => config('services.anthropic.model'),
            'max_tokens' => 1024,
            'messages'   => [
                ['role' => 'user', 'content' => $request->message],
            ],
        ]);

        foreach ($stream as $event) {
            if ($event->type === 'content_block_delta') {
                echo 'data: ' . json_encode(['text' => $event->delta->text]) . "\n\n";
                ob_flush();
                flush();
            }
        }
    }, 200, [
        'Content-Type'  => 'text/event-stream',
        'Cache-Control' => 'no-cache',
    ]);
}
```

<Callout type="warning">
เก็บ API key ใน `.env` เท่านั้น — ห้าม expose ไป frontend เรียกผ่าน Laravel backend เสมอ
</Callout>

## Rate Limiting & Cost Control

```php
// middleware
public function handle(Request $request, Closure $next)
{
    $user = $request->user();
    $key = 'ai-queries:' . $user->id;

    if (RateLimiter::tooManyAttempts($key, 20)) {
        return response()->json(['error' => 'เกิน quota รายวัน'], 429);
    }

    RateLimiter::hit($key, 86400);
    return $next($request);
}
```

## สรุป

| Task | Approach |
|---|---|
| Basic chat | `ClaudeService::chat()` |
| Conversation | `chatWithHistory()` with message array |
| Streaming | SSE + `createStreamed()` |
| Security | Backend proxy + rate limit |
| Cost | Log token usage per user |
