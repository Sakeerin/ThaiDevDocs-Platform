## ทำไม Docker กับ Laravel?

Docker ทำให้ environment เหมือนกันทั้ง dev และ production — ไม่มีปัญหา "works on my machine" และ scale ได้ง่าย

---

## Multi-stage Dockerfile

```dockerfile
# Dockerfile
FROM composer:2 AS vendor
WORKDIR /app
COPY composer.json composer.lock ./
RUN composer install --no-dev --no-scripts --prefer-dist --optimize-autoloader

FROM node:20-alpine AS frontend
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM php:8.3-fpm-alpine AS app
RUN apk add --no-cache \
    libpng-dev libjpeg-turbo-dev freetype-dev \
    libzip-dev icu-dev oniguruma-dev \
    && docker-php-ext-configure gd --with-freetype --with-jpeg \
    && docker-php-ext-install pdo_mysql gd zip intl opcache bcmath pcntl

COPY --from=vendor /app/vendor /var/www/html/vendor
COPY --from=frontend /app/public/build /var/www/html/public/build
COPY . /var/www/html

WORKDIR /var/www/html
RUN chown -R www-data:www-data storage bootstrap/cache

USER www-data
EXPOSE 9000
CMD ["php-fpm"]
```

## PHP Opcache Config

```ini
; docker/php/opcache.ini
opcache.enable=1
opcache.memory_consumption=256
opcache.max_accelerated_files=20000
opcache.validate_timestamps=0
opcache.preload=/var/www/html/preload.php
```

## Nginx Sidecar

```nginx
# docker/nginx/default.conf
server {
    listen 80;
    root /var/www/html/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass app:9000;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

## Entrypoint Script

```bash
#!/bin/sh
# docker/entrypoint.sh
set -e

php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan migrate --force

exec "$@"
```

## Health Check

```dockerfile
HEALTHCHECK --interval=30s --timeout=5s --retries=3 \
  CMD php artisan inspire > /dev/null || exit 1
```

```php
// routes/web.php — dedicated health endpoint
Route::get('/health', fn () => response()->json([
    'status' => 'ok',
    'database' => DB::connection()->getPdo() ? 'connected' : 'failed',
]));
```

## Production Tips

<Callout type="tip">
1. ใช้ multi-stage build — image สุดท้ายไม่มี node/composer dev tools
2. Pin PHP version ให้ตรงกับ production
3. รัน queue worker เป็น container แยก
4. ใช้ read-only filesystem สำหรับ code (mount storage เป็น volume)
</Callout>
