## Docker Compose สำหรับ Dev

Docker Compose รัน Laravel stack ทั้งหมดด้วยคำสั่งเดียว — PHP, Nginx, MySQL, Redis, Mailpit

---

## docker-compose.yml

```yaml
# docker-compose.yml
services:
  app:
    build:
      context: .
      dockerfile: docker/Dockerfile.dev
    volumes:
      - .:/var/www/html
      - ./docker/php/local.ini:/usr/local/etc/php/conf.d/local.ini
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_started
    networks:
      - laravel

  nginx:
    image: nginx:alpine
    ports:
      - "8080:80"
    volumes:
      - .:/var/www/html
      - ./docker/nginx/default.conf:/etc/nginx/conf.d/default.conf
    depends_on:
      - app
    networks:
      - laravel

  mysql:
    image: mysql:8.0
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: secret
      MYSQL_DATABASE: laravel
      MYSQL_USER: laravel
      MYSQL_PASSWORD: secret
    volumes:
      - mysql_data:/var/lib/mysql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 5
    networks:
      - laravel

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    networks:
      - laravel

  queue:
    build:
      context: .
      dockerfile: docker/Dockerfile.dev
    command: php artisan queue:work --sleep=3 --tries=3
    volumes:
      - .:/var/www/html
    depends_on:
      - mysql
      - redis
    networks:
      - laravel

  mailpit:
    image: axllent/mailpit
    ports:
      - "8025:8025"
      - "1025:1025"
    networks:
      - laravel

volumes:
  mysql_data:

networks:
  laravel:
    driver: bridge
```

## .env สำหรับ Docker

```bash
APP_URL=http://localhost:8080

DB_CONNECTION=mysql
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=laravel
DB_USERNAME=laravel
DB_PASSWORD=secret

REDIS_HOST=redis
CACHE_STORE=redis
QUEUE_CONNECTION=redis
SESSION_DRIVER=redis

MAIL_MAILER=smtp
MAIL_HOST=mailpit
MAIL_PORT=1025
```

<Callout type="info">
ใน Docker ใช้ **service name** เป็น hostname — `DB_HOST=mysql` ไม่ใช่ `localhost`
</Callout>

## Dev Dockerfile

```dockerfile
# docker/Dockerfile.dev
FROM php:8.3-fpm

RUN apt-get update && apt-get install -y \
    git curl zip unzip libpng-dev libzip-dev \
    && docker-php-ext-install pdo_mysql gd zip pcntl

COPY --from=composer:2 /usr/bin/composer /usr/bin/composer

WORKDIR /var/www/html
```

## คำสั่งที่ใช้บ่อย

```bash
# เริ่ม stack
docker compose up -d

# ติดตั้ง dependencies
docker compose exec app composer install
docker compose exec app npm install && npm run dev

# Migration
docker compose exec app php artisan migrate

# ดู logs
docker compose logs -f queue

# หยุดและลบ containers
docker compose down

# ลบ volumes ด้วย (reset database)
docker compose down -v
```

## Sail Alternative

Laravel Sail เป็น official Docker dev environment:

```bash
composer require laravel/sail --dev
php artisan sail:install
./vendor/bin/sail up -d
./vendor/bin/sail artisan migrate
```

<Callout type="tip">
Sail เหมาะกับ quick start — custom compose เหมาะเมื่อต้อง mirror production setup มากขึ้น
</Callout>
