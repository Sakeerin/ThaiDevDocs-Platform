## ภาพรวม

Laravel มีสองวิธีหลักในการคุยกับ database:

| | **Query Builder** | **Eloquent ORM** |
|---|---|---|
| สิ่งที่ return | `stdClass` หรือ array | Model object |
| ความเร็ว | เร็วกว่าเล็กน้อย | ช้ากว่าเล็กน้อย |
| Features | SQL-level operations | Relationships, Events, Casting |
| Syntax | `DB::table('orders')` | `Order::query()` |

---

## Query Builder

Query Builder คือ interface ที่ช่วยสร้าง SQL query แบบ fluent โดยไม่ต้องเขียน SQL ดิบ

```php
use Illuminate\Support\Facades\DB;

// ดึงออเดอร์ทั้งหมด
$orders = DB::table('orders')->get();

// มี WHERE, ORDER BY, LIMIT
$orders = DB::table('orders')
    ->where('status', 'completed')
    ->where('total_amount', '>=', 1000)
    ->orderByDesc('created_at')
    ->limit(50)
    ->get();

// JOIN
$orders = DB::table('orders')
    ->join('customers', 'orders.customer_id', '=', 'customers.id')
    ->select('orders.*', 'customers.name as customer_name')
    ->get();

// Aggregate
$totalRevenue = DB::table('orders')
    ->where('status', 'completed')
    ->sum('total_amount');

$orderCount = DB::table('orders')->whereDate('created_at', today())->count();
```

## Eloquent ORM

Eloquent ห่อหุ้ม database table เป็น Model object พร้อม features เพิ่มเติม

```php
use App\Models\Order;

// ดึงออเดอร์ทั้งหมด
$orders = Order::all();

// มี WHERE, ORDER BY, LIMIT
$orders = Order::where('status', 'completed')
    ->where('total_amount', '>=', 1000)
    ->latest()
    ->limit(50)
    ->get();

// Access relationship
foreach ($orders as $order) {
    echo $order->customer->name; // ใช้ relationship ได้เลย
}

// Aggregate
$totalRevenue = Order::where('status', 'completed')->sum('total_amount');
```

## เปรียบเทียบ Feature ที่สำคัญ

### Relationships

```php
// ✅ Eloquent: ใช้ relationship ได้โดยตรง
$order = Order::with('customer', 'items.product')->find(1);
echo $order->customer->name;

// ❌ Query Builder: ต้อง JOIN เอง
$order = DB::table('orders')
    ->join('customers', 'orders.customer_id', '=', 'customers.id')
    ->where('orders.id', 1)
    ->first();
```

### Model Events & Observers

```php
// ✅ Eloquent: มี lifecycle events
class Order extends Model
{
    protected static function booted(): void
    {
        // รัน automatic เมื่อสร้าง order ใหม่
        static::creating(function (Order $order) {
            $order->order_number = Order::generateOrderNumber();
        });
    }
}

// ❌ Query Builder: ไม่มี events — ต้องจัดการเอง
```

### Attribute Casting

```php
// ✅ Eloquent: cast type อัตโนมัติ
class Order extends Model
{
    protected $casts = [
        'metadata'   => 'array',      // JSON → array อัตโนมัติ
        'paid_at'    => 'datetime',   // string → Carbon อัตโนมัติ
        'is_express' => 'boolean',
    ];
}

$order = Order::find(1);
echo $order->metadata['shipping_note']; // เข้าถึง array ได้เลย
echo $order->paid_at->format('d/m/Y'); // Carbon method ใช้ได้เลย

// ❌ Query Builder: ต้อง cast เอง
$order = DB::table('orders')->find(1);
$metadata = json_decode($order->metadata, true); // ต้อง decode เอง
```

## เมื่อไหร่ใช้ Query Builder?

### 1. Bulk Operations ที่ต้องการความเร็ว

```php
// ✅ Query Builder: เร็วกว่ามาก ไม่โหลด Model
DB::table('orders')
    ->where('created_at', '<', now()->subYears(2))
    ->delete();

// ❌ Eloquent: โหลด record ทุกตัวก่อน delete — ช้า
Order::where('created_at', '<', now()->subYears(2))->delete();
// หมายเหตุ: Eloquent delete() โดยตรงบน query ก็ไม่โหลด Model
// แต่ถ้าต้องการ fire events ต้องใช้ ->each(fn($o) => $o->delete())
```

### 2. Complex Aggregate Queries

```php
// รายงานยอดขายรายวัน — ซับซ้อนเกินสำหรับ Eloquent
$report = DB::table('orders')
    ->selectRaw('DATE(created_at) as date')
    ->selectRaw('COUNT(*) as order_count')
    ->selectRaw('SUM(total_amount) as revenue')
    ->selectRaw('AVG(total_amount) as avg_order_value')
    ->where('status', 'completed')
    ->whereBetween('created_at', [now()->startOfMonth(), now()->endOfMonth()])
    ->groupByRaw('DATE(created_at)')
    ->orderByRaw('DATE(created_at)')
    ->get();
```

### 3. Cross-table Operations ที่ไม่มี Model

```php
// ดึงข้อมูลจาก table ชั่วคราว หรือ view
$summary = DB::table('monthly_sales_summary')
    ->where('year', 2026)
    ->get();
```

## เมื่อไหร่ใช้ Eloquent?

### 1. CRUD ทั่วไป

```php
// ✅ อ่านเข้าใจง่าย มี type safety
$order = Order::create([
    'customer_id'    => $customer->id,
    'total_amount'   => 1500,
    'payment_method' => 'promptpay',
    'status'         => 'pending_payment',
]);
```

### 2. เมื่อต้องใช้ Relationships

```php
$customer = Customer::with(['orders.items.product', 'addresses'])->find(1);
```

### 3. เมื่อต้องการ Model Events

```php
// ส่ง email เมื่อ order status เปลี่ยน
class Order extends Model
{
    protected static function booted(): void
    {
        static::updated(function (Order $order) {
            if ($order->wasChanged('status') && $order->status === 'shipped') {
                Mail::to($order->customer)->send(new OrderShippedMail($order));
            }
        });
    }
}
```

### 4. ทำงานร่วมกับ Auth และ Policies

```php
// Eloquent Model ทำงานกับ Policy และ Gate ได้โดยตรง
$this->authorize('update', $order);
```

## สรุปการตัดสินใจ

```text
ใช้ Eloquent เมื่อ:
  ✅ CRUD ปกติ
  ✅ ต้องการ Relationships
  ✅ ต้องการ Model Events / Observers
  ✅ ทำงานกับ Auth / Policies
  ✅ ต้องการ Attribute Casting

ใช้ Query Builder เมื่อ:
  ✅ Bulk insert/update/delete (ประสิทธิภาพสูง)
  ✅ Complex aggregate / reporting queries
  ✅ Raw SQL ที่ Eloquent ทำไม่ได้
  ✅ ดึงข้อมูลจาก table ที่ไม่มี Model
```

<Callout type="tip">
ในโปรเจคจริง ใช้ทั้งสองร่วมกัน — Eloquent สำหรับ business logic, Query Builder สำหรับ reporting และ bulk operations
</Callout>
